# Privacy — plain words

## Stays home
- Photos, text, names stay on your phone + your Docker laptop.
- No cloud call for guests. Ever.

## Goes out (only with your tap + account)
- Sync to your Postgres, share link, cloud AI (numbers hidden first).
- Mail OTP via ZeptoMail. Push via FCM.

## Your rights
- See: export my data (1 JSON file).
- Delete: wipe on phone + server (`DELETE /me` clears cache + rows).
- Logs: 30 days max, no doc text in crash logs.

## Kids / school / NGO lists
- Treat as sensitive: local only. Ask a lawyer before real-names beta.
