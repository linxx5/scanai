# Cost model — $0 local first

## Free quota (PRD §47)
- Free: 5 picture scans. Counted on phone + server. Use max, not sum.

## Local cost now
- Docker laptop: $0. Limit = your disk + RAM.
- Builds: GitHub Actions free minutes + `flutter build` on laptop $0.
- Mail: Mailpit local $0. Real mail: ZeptoMail cheap per mail.
- Pay: Paystack test $0. Live: small cut per sale only.

## Cloud later (only if you grow)
- Web: Netlify free start.
- Files: R2, no fee to download (good for PDFs).
- AI: Groq free cap + Gemini free cap, then capped per plan. Cache first.

## Guard
- No cloud call for guest.
- AI + batch over free = need account + tap + quota check.
